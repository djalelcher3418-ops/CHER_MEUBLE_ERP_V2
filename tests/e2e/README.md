# الاختبار الشامل (e2e)

يشغّل التطبيق المبني فعليًا على Postgres 16 حقيقي مع PostgREST (نفس محرك Supabase)
ودالتي `send-push` و`manage-users` تحت Deno، ثم يقوم بدور المدير والعامل في متصفح بحجم هاتف:
مواد، شراء، زبون، طلبية بعربون، الورشة، الرواتب، المصاريف، إنشاء حساب، الرسائل، إخراج مواد
لطلبية، تسليم ودفع، الفاتورة، التقرير، النسخة الاحتياطية، إيقاف حساب. بعد كل خطوة يتحقق من قاعدة البيانات.

- `supabase-stubs.sql`: ما يوفّره Supabase (الأدوار، `auth.uid()`، التخزين) بأبسط شكل
- `gateway.mjs`: يخدم التطبيق ويمرر `/rest/v1` إلى PostgREST، ويحاكي الدخول والتخزين
- `flow.mjs`: خطوات الاختبار

```
PG_SOCKET_DIR=/var/lib/postgresql POSTGREST=/path/to/postgrest DENO=/path/to/deno tests/e2e/run.sh
```

اختبار قاعدة البيانات وحده لا يحتاج أي شيء من هذا: `npm run test:db`

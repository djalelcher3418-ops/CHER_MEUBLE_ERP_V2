# CHER_MEUBLE_ERP_V2

أدوات ورشة **شير موبل** للأثاث. كل أداة صفحة HTML مستقلة تُفتح مباشرة في المتصفح.

| المجلد | الأداة | الوصف |
|---|---|---|
| `designer/` | مصمم الأثاث | تصميم الأسرّة والغرف بعرض ثلاثي الأبعاد، مخطط قصّ الألواح والعوارض، ملصقات القطع، حساب السعر، تتبّع الإنتاج والبقايا. |
| `team/` | فريق شير موبل | دردشة بين المدير والعمال، بطاقات الطلبيات، الإعلانات، حساب الغيابات والتسبيقات والرواتب. يعمل على Firebase. |

## التشغيل

افتح `designer/index.html` أو `team/index.html` في المتصفح.
تطبيق الفريق يحتاج اتصالاً بالإنترنت لأنه يستعمل Firebase (مشروع `cher-meuble-team`).
